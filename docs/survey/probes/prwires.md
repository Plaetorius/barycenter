## Findings
- Only GlobeNewswire allows a direct keyword feed. A cheap discovery set: keywords `nuclear`, `fusion energy`, `small modular reactor`, `SMR`, `uranium`, `HALEU`, `tokamak`, `stellarator`. Each call returns 20 items so poll at least every few hours; the nuclear feed spanned about 5 days at test time.
- Precision is low. Fusion keyword feed included a Global Times piece, an IBN "coverage initiation" and a stock-promotion item. Use a classifier on title+description, then fetch the release page for the `llm` extraction only if the issuer or wire ToS permits it; otherwise store the feed item (title, link, date) as a pointer and fetch the issuer's own release.
- Oklo's SPAC release was distributed via Business Wire (see its own page, `42c025c4d300`), so Business Wire carries some of the exact releases we want but is the one wire we cannot automate. Substitute: the same release is mirrored on the company newsroom and SEC 8-K exhibits (for public issuers).
- Wire RSS gives only a teaser `description`; amount/lead/participants need the full release.
